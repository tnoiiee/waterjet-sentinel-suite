# Stage 0.2.1A — Spike contracts (synthetic)

**Status:** SYNTHETIC SPIKE CONTRACT — NOT A PRODUCTION CONTRACT. The Production transport and
contract format remain `[OPEN]`. Types: [`operational.ts`](operational.ts). Classification:
[`classify.mjs`](classify.mjs). Structural validator: [`validate.mjs`](validate.mjs). Example
messages: [`fixtures/`](fixtures/) (generated by `scenario-runner/make-fixtures.mjs`).

## Delivery model

| Rule | Spike behaviour |
| --- | --- |
| Authority | The Node harness owns all operational state. The UI owns only selection and view state. |
| Revision | One monotonic integer per published state. Every Delta carries `previousRevision` and `revision`. |
| First message | Every SSE connection (initial or reconnect) starts with a full `OperationalSnapshot`. `Last-Event-ID` is ignored. |
| Delta content | Only changed Sensor records (whole-record replacement) and changed singletons. Absent key = unchanged; `activeJob: null` = cleared. |
| Gap | `previousRevision !== current revision` → the UI applies nothing, closes the stream, and reopens it to get a fresh Snapshot. |
| Reconnect | Full store replacement. No Delta replay, no command replay, no inference from the stale cache. |
| Slow client | A client whose socket buffer exceeds the bound is closed; it reconnects and receives a Snapshot. |
| Commands | HTTP POST, token protected (`X-Spike-Token`), never queued or replayed by the UI. |
| Folding | 208 Thermocouple channels are folded into 104 `SensorPresentationState` records in the runtime. |

## Classification and quality (approved spike rule)

- Dirty Score > threshold → `DIRTY`; ≤ threshold → `CLEANER`. The threshold comes from the
  Synthetic Published Configuration.
- `UNCERTAIN` keeps the last validated classification (`classificationBasis: LAST_VALIDATED`);
  a new uncertain value never changes it; with no last validated value → `NOT_CLASSIFIED`.
- `BAD`, `STALE`, `DISABLED` → `NOT_CLASSIFIED`.

All synthetic values are labelled **SYNTHETIC SPIKE PARAMETER — NOT A PRODUCTION VALUE**.
